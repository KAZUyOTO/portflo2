01Introduction

This project explores the dominant colors in movie posters from different eras. By analyzing posters, we can gain insights into visual trends and artistic preferences over time. It combines my passion for movies, design, and data analysis to reveal fascinating patterns in poster colour palettes.

02Objective

  • Extract the most dominant colors from movie posters.
  • Analyze how those palettes have shifted across decades.
  • Visualise the findings in an aesthetically pleasing way.

03Dataset

100 movie posters downloaded from IMDb. Filenames structured as <imdb_rating>_<imdb_id>.<ext> to keep metadata embedded in the file system.

04Tools & Libraries

  • OpenCV — image processing

Step 2 — Extract dominant colors

Used KMeans clustering on the pixel array of each poster to find the 20 most dominant colours. Each image is read with OpenCV, converted BGR→RGB, reshaped into a list of pixels, and clustered.

python 
import os, cv2, numpy as np
from sklearn.cluster import KMeans
import matplotlib.pyplot as plt

def extract_dominant_colors(image_path, num_colors=20):
    image = cv2.imread(image_path)
    image = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)
    pixels = image.reshape(-1, 3)
    kmeans = KMeans(n_clusters=num_colors)
    kmeans.fit(pixels)
    return kmeans.cluster_centers_

def plot_colors(colors):
    plt.figure(figsize=(12, 2))
    plt.imshow([colors.astype(int)])
    plt.axis('off'); plt.show()

06Analysis

  • 2020 and after — darker, moodier colours; a trend toward dramatic themes.
  • Early 2010s — bright, vibrant colours; optimism and lively storytelling.
  • Early 2000s — a mix of dark & earthy tones, balancing drama and grounding.
  • Early 1900s — earthy, subdued tones; characteristic vintage aesthetic.
